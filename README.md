# 🏡 BT RealEstate – Django Based Real Estate Web Application

## 📌 Overview
BT RealEstate is a **full-stack real estate web application** built with Django.  
It allows users to browse, search, and filter property listings, while admins can manage properties easily through the Django admin panel.  

The project demonstrates **backend development with Django**, **database integration**, and **responsive frontend design**.

---

## 🚀 Features
- User-friendly interface for browsing property listings  
- Property search and filtering by price, location, and more  
- Secure authentication (user registration & login)  
- Admin dashboard for managing property listings  
- Responsive frontend design using **HTML, CSS, Bootstrap, and JavaScript**  
- PostgreSQL database integration  

---

## 🛠️ Tech Stack
- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, Bootstrap, JavaScript  
- **Database:** PostgreSQL  
- **Version Control:** Git, GitHub
